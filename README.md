## 💻 Local Development

To run this project locally on your machine:

### Option 1: Python HTTP Server (Recommended)
```bash
# In the project root directory
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

## 🚀 Deployment to Netlify & GitHub

### Pushing to GitHub
```bash
git add .
git commit -m "Upgrade portfolio: Modern UI/UX, verified client projects, dark mode & technical SEO"
git push origin main
```

### Netlify Deployment
1. Log in to [Netlify](https://app.netlify.com/).
2. Connect your GitHub repository: `Nitachaudhari/Nitachaudhari.github.io`.
3. Set Build Command: *(Leave blank - this is a static site)*.
4. Set Publish Directory: `.` *(Root directory)*.
5. Click **Deploy Site**.
6. When forms are submitted, Netlify automatically captures inquiries in the **Forms** tab on your Netlify dashboard!
